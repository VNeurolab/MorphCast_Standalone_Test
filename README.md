# MorphCast Test Lab

Start with **guide.html** for the complete illustrated-by-interface usage guide, deployment steps, key placement, expected output, export format and troubleshooting.

## Quick start

1. Extract all files. Open index.html for an immediate simulated demo.
2. Upload the extracted contents (not the ZIP) into a GitHub repository root.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Open your Pages URL. No license is needed for Demo mode.
5. Later choose Live and paste your MorphCast **HTML5 SDK license key** into the page.

No npm, build, server or database required. The SDK is loaded only in Live mode.
Keep config.js blank unless you deliberately want a publicly embedded client license.
Never upload session exports or participant files into the repository.

Files: index.html (dashboard), style.css (appearance), app.js (behavior), config.js (optional license/config), guide.html (complete guide).

This is a standalone integration test, not a Talent BRAIN/Pavlovia integration.
Live authentication and camera analysis require verification with a valid license.
