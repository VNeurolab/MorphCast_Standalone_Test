SETUP / TEST / EXPORT

Your first MorphCast test

This standalone app targets the MorphCast Emotion AI HTML5 SDK v1.17. It is separate from Talent BRAIN, Pavlovia and your participant spreadsheets. There is no backend, installation step or build command.

1 / Deploy to GitHub Pages

  1. Extract the ZIP. Create a new GitHub repository, for example morphcast-test. A public repository is the simplest option for free Pages hosting. Do not upload participant files or exports.
  2. Choose Add file → Upload files. Upload the contents of the extracted folder, including index.html, style.css, config.js, app.js and guide.html. Place index.html directly in the repository root, not inside another folder. Commit the files to main.
  3. Open Settings → Pages. Select Deploy from a branch, then main and /(root). Save.
  4. Wait for deployment to finish. Open the URL shown in Pages, normally https://YOUR-USERNAME.github.io/morphcast-test/. Use HTTPS.
  5. For later edits, replace the changed files in the repository and commit. Pages republishes them. Hard-refresh your browser if the old version remains.

2 / Test now without a key

  1. Open the page and leave Demo — simulated data selected.
  2. Click Start demo. The face count becomes 1 and expression bars change. No camera prompt should appear. All generated values are artificial.
  3. Click Stop session, then download CSV and JSON. The stopped dashboard clears current metrics; the captured events remain exportable.
  4. To simulate the additional outputs, enable the optional-module checkbox before starting a new session. Export first: starting again clears the previous capture.

You can also double-click index.html for an offline demo. For live testing, use GitHub Pages or a local server such as python -m http.server 8000, opened at http://localhost:8000.

3 / Where to put the API key

Recommended: obtain an Emotion AI HTML5 SDK license from MorphCast, select Live mode and paste it into the field named MorphCast SDK license key. The page keeps it for the current session only; it is not stored by the app in localStorage or exported.

Optional code setup: in config.js, replace the empty string after licenseKey::

window.MORPHCAST_CONFIG = {
  licenseKey: 'PASTE_YOUR_BROWSER_SDK_LICENSE_HERE',
  sdkUrl: 'https://ai-sdk.morphcast.com/v1.17/ai-sdk.js'
};

A key placed in config.js is public. This SDK uses a client-side license, not a hidden server credential. Check the license's permitted domains and usage settings with MorphCast; use your GitHub Pages hostname where applicable. Do not paste an account password or a private REST API secret. If MorphCast gives you a REST endpoint rather than an HTML5 SDK license, this integration will need an adapter and potentially a backend.

4 / Run a live test

  1. Select Live, enter the license and check the camera consent box. Keep optional modules off for the first attempt.
  2. Click Start live test. Allow camera access. Internet is needed to load the SDK, models and licensing services.
  3. Keep one face in the frame with even lighting. Wait for the preview and captured-event count. A started SDK alone is not proof of valid results: check that FACE_EMOTION events actually arrive.
  4. Try a neutral expression, a smile and a brief look away. Inspect changes without assuming a particular result.
  5. Stop, export, and check the file's mode is live. Repeat with optional modules if your license includes them. Reload before changing modules or license after a live initialization.

5 / Expected output

OutputWhat you will see
CameraMirrored preview of the SDK's sampled frames; no recording.
Face countSmoothed detector count. Use one person for this test.
ExpressionsAngry, Disgust, Fear, Happy, Neutral, Sad and Surprise, displayed as percentages. Raw exported scores range from 0 to 1.
Top expressionSDK dominant label, or the largest score if the label is absent.
Optional attentionDisplayed as a percentage; exported on a 0–1 scale.
Optional arousal / valenceSigned values from −1 to +1. These are model estimates.
Unavailable outputA dash, not a zero. Current metrics clear on stop or stale emotion output.

These outputs are facial-analysis estimates. They do not establish a person's actual internal feelings or Talent BRAIN capacity scores. This tool performs no psychological scoring or participant evaluation.

6 / Understanding exports

CSV: one row per captured module event, with UTC timestamp, elapsed milliseconds, mode, module and the relevant metrics. Empty cells mean that metric is absent from that event. Rows from different modules are asynchronous; they are not synchronized trials. Open the CSV in Excel, and filter by module. All raw numerical scales are preserved.

JSON: session metadata and captured SDK event payloads, before app-level flattening. SDK outputs can already be smoothed; “raw payload” does not mean unfiltered model predictions. Filenames include demo/live and session time. Keys and camera images are excluded.

Export after Stop for a complete session end time. Export while running gives a snapshot only. The 20,000-event or 10-minute limit ends capture automatically. There is no automatic cloud backup. Downloads go to your browser's usual download location. Closing or refreshing the tab clears the capture.

7 / Troubleshooting

SymptomAction
404 after deploymentConfirm index.html is in the publishing root and inspect the repository's Pages deployment status.
Live cannot startConfirm the license is an HTML5 SDK license, active and permitted for this site. Test with optional modules disabled.
SDK download failureCheck internet/firewall access to ai-sdk.morphcast.com. After restoring access, reload and retry.
No camera or permission errorAllow camera access in browser site settings; close other camera apps and use HTTPS. Reload.
Waiting indefinitely during loadingCheck for a hidden permission dialog, blocked model downloads or license errors. Close the tab to end a stalled start, then retry. Never assume capture started without events.
Preview but no emotion dataCheck lighting, face position and licensed modules. Inspect browser developer tools if it continues. Do not interpret missing outputs as zero.
Camera stays active after StopClose the tab to release it. The app reports stop failures rather than confirming success.
Optional values stay blankEnable the checkbox before loading, verify your license and reload. Inspect JSON to see whether those events arrived.

8 / Data and test boundaries

This app does not upload test events or camera frames to your GitHub repository, Apps Script or Pavlovia. It retains captured outputs in page memory until download or refresh. The live SDK is third-party software and makes its own loading/licensing requests; review MorphCast's terms and privacy information for its behavior. Start with your own camera for this integration test.

Verified locally: JavaScript syntax, demo generation, export formatting, missing-key validation and mocked SDK lifecycle. Actual license acceptance and real-camera output are not verified without your license.
